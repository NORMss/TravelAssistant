# Работа в этом репозитории

Приложение для путешествий: офлайн-план поездки плюс языковая модель, которая
помогает его собрать. Подробности — [README.md](README.md) и `docs/`.

## Перед тем как писать код

1. **Прочитать [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)** — правила
   зависимостей между модулями там не рекомендация, а условие: нарушив их,
   проект разъедется за несколько недель.
2. **Для интерфейса — [docs/DESIGN.md](docs/DESIGN.md)**, особенно чек-лист
   нового экрана в конце.
3. **Найти задачу в [docs/ROADMAP.md](docs/ROADMAP.md)** и загрузить указанный
   там скилл через `Skill`.

## Правила, которые легко нарушить по незнанию

* **AGP 9 сам включает Kotlin.** Применять `org.jetbrains.kotlin.android`
  нельзя — сборка падает с явной ошибкой. `CommonExtension` потерял параметры
  типа: конвенции из примеров под AGP 8 не компилируются.
* **Новый модуль — три строки.** `alias(libs.plugins.travelassistant.android.feature)`
  плюс `namespace`. Не копировать чужой `build.gradle.kts` целиком.
* **Версии только в `gradle/libs.versions.toml`.** Уровни SDK и Java — только в
  `build-logic/.../Config.kt`.
* **material3 намеренно выше версии из BOM** (1.5.0-beta01). Причина записана в
  каталоге рядом. Не «чинить» это обратно.
* **Удаление — это `deletedAt`, а не `DELETE`.** Во всех запросах есть
  `deleted_at IS NULL`. Иначе удалённая запись вернётся при синхронизации.
* **Анимации — через `Motion`, формы — через `TravelShapeTokens`.** `tween(300)`
  в коде экрана — повод для правки.
* **Модель не пишет в план.** Она возвращает `PlanProposal`, применяет
  пользователь. Этот инвариант не обходится «для удобства». То же для
  распознавания достопримечательностей: подпись — предложение до подтверждения.
* **Личное не кладётся в `TripTemplate`.** В нём нет полей для броней, рейсов и
  участников, и добавлять их нельзя: шаблон уезжает в публичный репозиторий.
  После правки `tools/make_demo_template.py` обязательно
  `./gradlew :core:data:testDebugUnitTest`.
* **Новый экран приносит свой тур подсказок.** Ключи — значения `GuideKey`,
  не строки.
* **`contentPadding` обязателен** для скроллящихся экранов: навигация плавает
  над контентом, иначе последняя строка прячется под ней.

## Проверка работы

```bash
./gradlew :app:assembleDebug           # сборка
./gradlew test testDebugUnitTest       # тесты (сейчас 19, все зелёные)
```

На эмуляторе:

```bash
android run --apks app/build/outputs/apk/debug/app-debug.apk --device emulator-5554
android screen capture --device emulator-5554 -o /tmp/shot.png   # и посмотреть
android layout --device emulator-5554 --flat -o /tmp/layout.json # текст и координаты
```

Подключено может быть несколько устройств — `--device` обязателен.
**Правку интерфейса обязательно смотреть глазами на скриншоте.** Тест не ловит
перекрытый системной панелью элемент.

## Как вести задачу

Одна задача из ROADMAP — одна сессия, одна ветка, один коммит. Коммит
описывает, *почему* сделано так, а не что именно поменялось: что поменялось,
видно в диффе.

Если по ходу выясняется, что задача тянет за собой вторую, — лучше остановиться
и сказать об этом, чем сделать обе наполовину.

## Язык

Комментарии и документация — по-русски, как в BeijingTrip.
Код, идентификаторы и строки в коммитах — по-английски. Строки интерфейса пока
зашиты по-русски; вынос в ресурсы — задача 7.7.
